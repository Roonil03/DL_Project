# Dataset Instructions

This directory is intended to contain the Kaggle dataset for the Harry Potter Named Entity Recognition and Relation Extraction project.

## How to obtain the dataset
The dataset can be downloaded from Kaggle:
[https://www.kaggle.com/datasets/mkdsps/harry-potter-ner-re](https://www.kaggle.com/datasets/mkdsps/harry-potter-ner-re)

## License
The dataset is provided under the Apache 2.0 license according to the Kaggle page. Please verify this and any additional copyright constraints on the source text before redistributing.

## Setup
Download the dataset and extract the contents directly into this `data/` folder. The loader in `src/data_loader.py` will programmatically inspect and load the data.
