Where computationally feasible, implement statistical comparisons.

Possible methods:

* bootstrap confidence intervals
* paired bootstrap of daily strategy returns
* block bootstrap for time-series dependence
* model difference analysis

Do NOT blindly use ordinary i.i.d. tests on autocorrelated financial returns.

Prefer block bootstrap where possible.

The point is not statistical sophistication for its own sake.

The point is to avoid claiming that a tiny Sharpe difference is meaningful without uncertainty analysis.
